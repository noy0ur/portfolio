# Shaik Sameer — Personal Portfolio

Responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript. Designed to present a Computer Science graduate's skills, learning journey, and project portfolio.

## Features
- Responsive layout for mobile, tablet, and desktop
- Mobile navigation menu
- Light/dark theme toggle
- Filterable project cards (Python, Data & ML, Web & Apps)
- Skills, about, learning journey, and contact sections
- No build tools or package installation required

## Files
- `index.html` — page structure and portfolio content
- `style.css` — layout, responsive styles, and themes
- `script.js` — project list, filters, navigation, theme, and profile links

## Run locally
Open `index.html` in a modern browser. An internet connection is only needed for the optional Google Fonts import in `style.css`.

## Publish with GitHub Pages
1. Create a public repository named `my-portfolio` (or another name you prefer).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for the published URL to appear on the Pages settings screen.

## Personalize before publishing
1. In `script.js`, replace `YOUR-EMAIL@example.com`, `YOUR-USERNAME`, and `YOUR-LINKEDIN` with real profile details.
2. Add each real GitHub repository URL in the `projects` array. A blank URL currently displays “Repository link to add”.
3. Confirm project descriptions and status labels accurately represent what you have actually built and tested.
4. Remove skills you cannot yet discuss confidently in an interview.
5. Do not publish personal data or unredacted resumes.

## Important project-status note
Some cards describe project concepts or starter builds discussed during portfolio planning. They are not represented as finished products. Update each status after you have run, tested, and understood the project.
